# An Interactive Grid

Let's build a simple grid where you can click individual cells to
toggle them on and off.

This is a standalone HTML demo embedded directly into the article:

<iframe
    src="./interactable1/"
    height="380"
    title="Interactive grid demo">
</iframe>

## How it works

Each cell has two states: active and inactive.

Click any cell to toggle its state. The demo uses ordinary HTML, CSS,
and JavaScript, so it doesn't need any framework.

You could use the same approach for visualizing algorithms, exploring
data structures, or demonstrating Rust concepts.
